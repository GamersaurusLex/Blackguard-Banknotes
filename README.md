# Blackguard Banknotes

Blackguard uses banknotes as its visible currency.

- `N1` equals 1 copper piece.
- `N100` equals 1 gold piece.
- PF2e keeps its normal copper-piece accounting under the hood, preserving prices, wealth calculations, merchant math, and treasure value.

## World settings

- **Use Blackguard Banknotes** enables or disables the presentation layer.
- **Show Native Currency Values to GMs** adds the underlying PF2e denominations beside balances for troubleshooting.
- **Migrate Existing Balances** previews every owned actor with currency. Confirmation converts each balance to its exact copper-piece total, which the module displays as banknotes.

Actor sheets provide a banknote editor beside the currency balance. Item price fields accept values such as `N400` and save them as the equivalent native PF2e currency value.
