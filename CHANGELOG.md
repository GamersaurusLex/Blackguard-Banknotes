# Changelog

## 0.1.4

- Displays item prices as N-value banknotes across inventory details, item
  sheets, chat cards, and compendium item sheets. Native currency remains
  available to GMs through the existing hover-value setting.

## 0.1.3

- First Forge-ready release of **Blackguard Banknotes**.
- Displays PF2e currency as copper-value banknotes and includes the Blackguard
  banknote asset, Treasure display, N-value price entry, and balance migration.
